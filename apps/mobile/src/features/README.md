# features

Код фич: хуки, сторы, компоненты конкретного экрана. Экраны в `src/app/` только собирают фичи.

| Папка | Что внутри | Фаза |
|---|---|---|
| `library/` | список и карточки произведений, фильтры | 3 |
| `import/` | выбор файла, импорт MusicXML/MXL, загрузка на OMR | 2, 7 |
| `practice/` | сессия игры: стор, связка NoteInput → Matcher → NotationView | 4 |
| `progress/` | статусы фрагментов, карта сложности, расписание повторений | 5 |
| `lessons/` | сборка и прохождение мини-урока, стрик | 6 |
| `settings/` | MIDI-устройство, калибровка задержки, размер фрагмента | 4 |

Платформенные сервисы лежат в `src/services/`: `midi`, `notation`, позже `audio`, `db`, `api`.
Музыкальная логика — не здесь, а в `packages/score-core` и `packages/practice-engine`.
